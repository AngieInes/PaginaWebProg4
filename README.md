# Sitio web Mad Men

Sitio web responsive inspirado en la estética publicitaria de los años 60.

## Estructura

- `index.html` — página de inicio
- `temporadas.html` — las 7 temporadas
- `personajes.html` — personajes principales, organizados por mundo de la publicidad y familia de Don
- `galeria.html` — galería de imágenes
- `contacto.html` — formulario de contacto
- `css/estilos.css` — estilos principales
- `js/scripts.js` — JavaScript del menú y formulario
- `img/portada.jpg` — imagen oficial proporcionada
- `img/poster.jpg` — póster oficial proporcionado
- `img/logo-mad-men.png` — logotipo proporcionado

## Tecnologías

- HTML5 semántico
- CSS3 con Flexbox y diseño responsive
- JavaScript vanilla
- Font Awesome para iconos sociales
- Google Fonts para tipografías

Abrir `index.html` en un navegador para visualizar el sitio.


## Temporadas y capítulos

La página `temporadas.html` ahora funciona como índice de las siete temporadas. Cada tarjeta enlaza a una página independiente (`temporada-1.html` a `temporada-7.html`) con el listado completo de capítulos. La serie tiene 92 episodios distribuidos en 7 temporadas.

- `curiosidades.html`: sección de curiosidades y datos de producción de la serie.
